Instructions
================================================== PROVIDED SOURCES AND CITATIONS ================================================== I will provide research papers, articles, references, project documents, and other academic sources as part of the project context. Treat the sources I provide as the authoritative source set for this paper. IMPORTANT: - Use the provided sources directly. - Cite the provided sources wherever their ideas, methods, findings, datasets, or claims are discussed. - Do NOT independently search for or verify the provided sources unless I explicitly ask you to do so. - Do NOT replace a provided source with another source merely because another source appears more recent or authoritative. - Preserve the authors, publication year, title, venue, and bibliographic information supplied with the source. - Do not invent missing bibliographic information. - If the supplied source contains incomplete citation information, use only the information that has been provided. - Do not fabricate DOI numbers, page numbers, volume numbers, issue numbers, or publishers. ================================================== CITATION REQUIREMENTS ================================================== Every substantive claim derived from a provided academic source should have an appropriate IEEE citation. Use IEEE numbered citation format: [1] [2] [3] For multiple sources: [1], [2] or: [1]–[3] Do not use author-year citations such as: (Tiwari et al., 2019) unless I explicitly request that style. Do not cite a source merely because it is present in the project. Cite it where its content actually supports the statement. ================================================== REFERENCE NUMBERING ================================================== Maintain one consistent numbering system throughout the paper. The first source cited in the manuscript becomes [1], the next new source becomes [2], and so on. If a source has already been assigned a number, reuse the same number throughout the entire paper. Do not assign multiple numbers to the same paper. The REFERENCES section must contain every source cited in the paper and only sources actually cited in the paper. ================================================== RELATED WORK ================================================== Use the provided literature to construct the Related Work section. Do not simply list the papers. Synthesize them by: - research approach, - methodology, - findings, - limitations, - evolution of the field, - relationship to the proposed system. Use citations immediately after the claims supported by each source. For example: Traditional ATS systems have primarily focused on extracting candidate information and applying predefined criteria for applicant scoring [1]. Subsequent approaches introduced semantic representations to improve resume–job matching [2], [3]. Transformer-based methods further improved contextual representation of resumes and job descriptions [4]. Do not make a claim from a source without citing that source. ================================================== SOURCE PRIORITY ================================================== When writing the paper, use this priority order: 1. Information explicitly provided in my project context. 2. Information contained in the academic sources I supplied. 3. Reasonable technical inference from the supplied research. 4. General technical knowledge only when necessary to connect the material. Do not use outside literature unless I explicitly ask for additional sources. ================================================== NO UNNECESSARY SOURCE CHECKING ================================================== Do not spend effort independently verifying the sources I supplied. The task is to use the supplied sources to construct the paper, not to perform a separate literature-verification exercise. Focus on: - correct citation placement, - accurate representation of the supplied sources, - synthesis of the literature, - consistent IEEE numbering, - and connection between prior work and the proposed research. ================================================== SOURCE-BASED ACCURACY ================================================== Do not attribute information to a source that is not contained in the supplied source. Do not exaggerate a paper's contribution. Do not describe a method as superior unless the supplied source provides evidence for that comparison. When discussing a source, accurately represent what that source actually reports. If the supplied sources disagree, present the disagreement objectively rather than silently choosing one. ================================================== FINAL REFERENCE CHECK ================================================== Before producing the final paper, internally check: 1. Every [n] citation has a corresponding reference. 2. Every reference in REFERENCES is cited somewhere in the manuscript. 3. The same paper never receives two different citation numbers. 4. Citation numbering is sequential according to first appearance. 5. Claims derived from literature have citations. 6. Citations are placed close to the claims they support. 7. No citation has been fabricated. 8. No provided source has been unnecessarily replaced.
